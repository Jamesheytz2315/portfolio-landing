# Portfolio

One-page portfolio built with React, TypeScript, Vite and Tailwind CSS.

## Run locally
```
npm install
npm run dev
```
Open the address it prints (usually http://localhost:5173).

## Build for production
```
npm run build
```
The finished site is created in `dist/`. Vercel runs this command automatically.

## Deploy
Push to GitHub, then import the repo on vercel.com (Framework Preset: Vite, Build Command: `npm run build`, Output Directory: `dist`).
